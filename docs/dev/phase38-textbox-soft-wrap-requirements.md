### 1.2 ★★ N0 · 现状即缺陷：`SetWordWrap(true)` 对 `TextBox` 是**半激活**，不是惰性

`SetWordWrap`/`IsWordWrap` 从 `TextWidget` 继承（`TextWidget.h:67/:70`），`TextBox` **不消费它**（★ v1.1 订正：`grep IsWordWrap` 于 `TextBox.cpp` = **0 命中**；v1.0 所称「仅 `:206` 一句注释命中」不实——`:206` 的注释提的是 `IsWrapLayoutActive`）。但「不消费」≠「无影响」——**`preferred` 这条通路会穿过继承链命中基类分支**：

```
TextBox::GetPreferredSize()                     TextBox.cpp:195   闸 = m_text.find('\n') != npos
  ├─ 含 \n   → MultilinePreferred()             :196 / :204-229   本类自数 \n，不看开关 ⇒ 不受影响
  └─ 不含 \n → TextWidget::GetPreferredSize()   :199（显式限定基类调用）
                 ├─ measurer == nullptr → 当前尺寸                TextWidget.cpp:423-427
                 └─ if (IsWrapLayoutActive())  :433
                      return { GetWidth(), layout.totalHeight }    :436
        ↓ 回到 TextBox :200-201
          return Size{ measured.width + pad*2, measured.height + pad*2 }   ★ 两轴**都**补 padding
```

⇒ **触发条件** = `SetWordWrap(true)` **且** 文本**不含 `\n`** **且** `GetWidth() > 0` **且** 有窗口（`IsWrapLayoutActive` 三条件，`TextWidget.cpp:123-129`）。
⇒ **后果（★ v1.1 重写 = 「长高」**+**「长宽」双症状）**：
① **长高** = `GetPreferredSize()` 报 `视觉行数 × L + 2p`（基类 `totalHeight` 经 `:201` **已补** padding），而 `OnPaint`（`:1355` 起）仍按 `\n` 分段画 **1 行** + 水平滚动 ⇒ `AutoSize()`（`Widget.cpp:470-483`，`GetPreferredSize` → 截断 → `SetSize`）把框凭空长高、内容贴顶、下方大片空白。
② ★★ **宽度棘轮（v1.0 漏项，P0-1）** = 基类 wrap 分支的宽取 **`GetWidth()`（当前宽）**（`:436`），`:201` 再 `+2p` ⇒ `AutoSize` 一次即 `W → W + 2p` ⇒ **再调一次 = `W + 4p`**（每次净增 `2p`，单调不收敛）。默认 `padding = 0` **掩盖**了它；但 Phase 37 实测 harness `ComposerBox` 是 **`padding = 6`**（引用未复跑）⇒ **每次 `AutoSize` 长 12px**——正打在「聊天输入框」这个唯一会命中的场景上。
⇒ **摘要「加一行即可」的收敛点因此不成立**（且比 v1.0 的判断更糟：不只是高度错，宽度还会随每次自动尺寸调用增长）。
★★ **v1.1 自我订正**：v1.0 在链图旁写「基类分支**不加** `TextBox` padding」、又把 `:201` 列为「含 `padding×2` 的站点」——两句话互斥，且第一句是**错的**：`:201` 正是给基类返回值补 padding 的那一行。⇒ **「高度有两个来源」不成立**（两来源都含 `2p`）；**真正的第二来源在宽**（基类取当前宽、非 wrap 分支取内容宽），后果如上 ②。
⇒ **由此产生一条硬约束（写入 D38-7）**：折行落地后，`TextBox` 的折行分支**必须**走本类 `MultilinePreferred`（宽恒 = `GetWidth()`，K8 契约③），**禁止**经基类 wrap 分支 `:433` 返回——否则 `2p` 加在「已经等于当前宽」的返回值上，棘轮原样保留。

### 1.4 数据结构层结论（E2 的正解，供初设直接取用）

`m_lineStarts`（`TextBox.h:349`）今天同时承担两件事：**行起点集合** + **靠相邻差隐含行尾**。软折行下第二件事必然失效（无 `\n` 可排）。同时注意该字段的注释已经与实现不符——`TextBox.h:349` 写「行数 = `size()-1`」，而实现按 **`size()` == 行数**（`OnPaint` `:1370` 取 `lineCount`、`GetMaxScrollOffset` `:529` 取 `size() × lineH`、`Up/Down` 末行界 `:1251` 取 `curLine + 1 >= size()`）⇒ 落地时必须一并订正该注释，**不得让实现者按注释的 `size()-1` 口径写折行代码**。

## §3 范围与非目标
